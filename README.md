Software Engineering project for helping students find compatible study partners.

## Tech Stack
- React + Vite
- TypeScript
- Supabase

## Setup

Clone repo:

git clone <repo-url>

Install dependencies:

npm install

Run locally:

npm run dev

## Project Structure

src/
  components/
  pages/
  services/
  types/

## Team Workflow
- Create feature branches
- Do not push directly to main
- Use clear commit messages
